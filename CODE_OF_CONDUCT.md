# Code of Conduct

Toolz is an independent open-source project. The goal is simple: build great tools and collaborate respectfully.

## Standards

- **Be respectful and constructive**: Disagree on technical merit with evidence, not personal attacks.
- **No harassment or abuse**: Toxicity, hate speech, trolling, doxxing, or unwanted advances will not be tolerated.
- **Keep it focused**: Issue trackers and discussions are for developing and improving Toolz, not spam, self-promotion, or political arguments.

## Enforcement

If someone is being toxic or harassing others in our GitHub repo or Discord, report it to **frerox.toolz@gmail.com**. I will review what happened and block/ban anyone who cannot interact like an adult.
